How clipping and Gaussian noise work

Each client trains on its own partition. It sends a model-weight update (the change from the current global model), not retinal images.

  1. Measure the update. The server calculates one L2 norm across all weight changes in that client's update.
  2. Clip unusually large updates. If the norm exceeds the clipping limit, every value in the update is scaled down together. This caps the update's overall size while preserving its direction.
  3. Add Gaussian noise. The server adds zero-mean random noise to the clipped weight values. The noise multiplier controls its strength; the per-weight scale also accounts for the number of model parameters.
  4. Aggregate the processed updates. FedAvg combines the resulting client models, weighting each by that client's number of training samples.

clipped update = update × min(1, clipping limit ÷ update norm)
